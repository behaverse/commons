# Behaverse commons

The texts, media and questionnaires that Behaverse's programs show to participants, kept in one place and free to reuse.

**Status: empty.** This repository was created on 2026-11-17. Its content has not been moved in yet.

## What it will hold

- **Messages.** Each text a participant reads, such as an instruction sentence or a questionnaire's prompt, and each image, video or audio clip they see or hear. A message is one file, with all its languages and a version for each text.
- **Questionnaires**, with their answer options, items and scoring.
- **Files that describe the messages**: the roles a message plays on a page, and the dimensions, constructs and topics of the questionnaires' texts.
